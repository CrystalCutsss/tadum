# Definition of Done для PR — Tadum

> Шаблон описания PR и чек-лист готовности. Копия — `.github/PULL_REQUEST_TEMPLATE.md` в репозитории. Пункты, помеченные **CI**, проверяются автоматически и блокируют merge; остальные подтверждает автор и ревьюер. Пункт, который к фиче не относится, помечается «н/п» с причиной, а не пропускается молча.

## Описание PR

**Бриф:** `TD-###` — ссылка на файл в Drive и на Issue
**Сценарии:** `SC-##` / `SP-##`
**Версия прототипа:** vN
**Что сделано (3–5 строк, для человека):**

**Скриншоты:** мобильный 360 px — AR и EN; десктоп 1280 px — AR и EN; светлая и тёмная тема (вставить или ссылка на артефакт CI)
**Как проверить на витрине / локально:** персона демо-режима, маршрут, шаги
**Отклонения от брифа и почему:**

## 1. Соответствие требованиям

- [ ] Реализован сценарий из брифа; критерии приёмки отмечены в брифе
- [ ] Не сделано ничего сверх брифа (раздел «Вне объёма» соблюдён)
- [ ] Права ролей соблюдены: действия недоступны в заблокированных статусах, скрытое для роли не отображается
- [ ] Внутренние стадии Odoo, скоринг и заметки UW не показываются; причина отказа — только из согласованного текста

## 2. Состояния

- [ ] loading (skeleton), empty, error с повтором, offline, blocked, normal — реализованы
- [ ] Длинный арабский текст и длинные названия не ломают макет (обрезка/перенос осознанные)
- [ ] Каждое состояние есть в Storybook в AR-RTL и EN-LTR — **CI** (Storybook-тесты)

## 3. Адаптивность и мобильность

- [ ] Макет от 360 px, без горизонтальной прокрутки на 360 / 768 / 1280 — **CI** (скриншоты)
- [ ] Цели касания ≥ 44 px, нижняя навигация не перекрывает контент, учтены safe-area iOS
- [ ] Клавиатура на мобильном не закрывает активное поле; `inputmode` задан для телефона и кода
- [ ] Проверено во встроенном браузере WhatsApp (скачивание файлов — прямые ссылки, нет `blob:`-загрузок)

## 4. RTL и LTR

- [ ] Нет физических классов `ml- mr- pl- pr- left- right- text-left text-right rounded-l/r border-l/r` — **CI** (ESLint + grep)
- [ ] Зеркалятся только направленные иконки (стрелки, шевроны, шкала прогресса); нейтральные — нет
- [ ] Порталы (Select, Popover, Sheet, Dialog, Toast) получают `dir`
- [ ] Телефон, IBAN, CR, суммы — изолированные LTR-фрагменты (`<bdi dir="ltr">`)
- [ ] Скриншоты AR и EN просмотрены глазами, различия осознанные — **CI** (визуальная регрессия)

## 5. Локализация

- [ ] Ни одной строки в коде; все тексты через ключи — **CI** (lint)
- [ ] Каждый ключ есть в `ar` и `en`; паритет проверен — **CI** (`i18next-parser --fail-on-warnings`)
- [ ] Для `count` заданы все формы множественного числа арабского (`zero / one / two / few / many / other`)
- [ ] Деньги, даты, числа, телефоны — только через `shared/i18n/format.ts` (западные цифры, григорианский календарь, SAR)
- [ ] Тексты прошли проверку TOV: нет запрещённых слов, третьи стороны только текстом, формула ошибок соблюдена; владелец текстов подтвердил

## 6. Дизайн-система

- [ ] Только токены (цвета, радиусы, тени, отступы, типографика); сырых hex / px нет — **CI** (lint)
- [ ] Используются компоненты `shared/ui` и `widgets`; новые компоненты согласованы с `design-system-owner` и добавлены в Storybook
- [ ] Шрифты: арабский — IBM Plex Sans Arabic, английский — Geist; арабский текст не падает в системный шрифт
- [ ] Светлая и тёмная темы проверены на изменённых экранах (скриншоты в обеих), цвета только через токены темы
- [ ] Файлы `src/styles/tokens.css` и `shared/ui/**` не менялись без отдельного согласования (хук защищает, но проверить)

## 7. Доступность (WCAG 2.2 AA)

- [ ] axe без нарушений уровня A/AA на изменённых маршрутах в AR и EN — **CI** (`@axe-core/playwright`)
- [ ] Весь сценарий проходится клавиатурой; фокус виден; порядок фокуса логичен в RTL
- [ ] У полей есть подписи и описания ошибок, связанные через `aria-describedby`
- [ ] Контраст текста ≥ 4.5:1, статусы различимы не только цветом (иконка/текст)
- [ ] Для загрузки файлов и прогресса есть текстовые эквиваленты и `aria-live`

## 8. Аналитика

- [ ] События из брифа вызываются на успешном и на ошибочном пути с указанными свойствами
- [ ] Имена событий есть в словаре `shared/analytics/events.ts` (типизированы) — **CI** (typecheck)
- [ ] Нет PII в свойствах событий (телефон, имена, суммы лимита) и в URL
- [ ] Вызовы `track` покрыты unit-тестом

## 9. Данные и архитектура

- [ ] Доступ к данным только через порты `shared/api/ports`; прямых обращений к моку нет
- [ ] `MockAdapter` воспроизводит нужные переходы статусов; персоны демо-режима обновлены
- [ ] Границы слоёв соблюдены (`shared → entities → features → widgets → pages → app`) — **CI** (eslint-plugin-boundaries, dependency-cruiser)
- [ ] Нет мёртвого кода и дублей — **CI** (knip, jscpd)
- [ ] `tsc --noEmit` без ошибок, `strict` не ослаблен — **CI**
- [ ] Изменения в контракте портов отражены в `docs/05-backend-contract.md`

## 10. Тесты

- [ ] Unit-тесты на логику (маппинг статусов, валидация, форматтеры) — **CI** (Vitest)
- [ ] Сценарий брифа и его ошибки — в Playwright, проекты `android-chrome` и `iphone-safari`, локали ar и en — **CI**
- [ ] Существующие тесты не удалены и не ослаблены; если тест изменён — причина в описании PR

## 11. Производительность и PWA

- [ ] Бюджет первого чанка не превышен — **CI** (size-limit)
- [ ] Тяжёлые маршруты и библиотеки (QR, графики, видео) загружаются лениво
- [ ] Lighthouse на `main`: performance ≥ 90, accessibility = 100, PWA installable — **CI** (ночной прогон)
- [ ] Новые ассеты (иконки, шрифты) попали в прекэш или осознанно исключены

## 12. Кроссбраузерность

- [ ] Smoke в профилях iOS Safari, Android Chrome, Chrome / Safari / Edge (две последние версии) — **CI** (Playwright-проекты)
- [ ] `100dvh`, `env(safe-area-inset-*)`, отсутствие зависимости от нестандартных API без фолбэка

## 13. Документация и релиз

- [ ] Changeset добавлен (тип изменения и человекочитаемое описание) — **CI**
- [ ] Коммиты по Conventional Commits — **CI** (commitlint)
- [ ] Storybook / README / ADR обновлены, если менялось поведение компонентов или архитектура
- [ ] Бриф в Drive обновлён: статус, отклонения, ссылка на PR
- [ ] Если PR закрывает версию vN — release notes в `06 Версии прототипа/vN.md` и запись в `registry.json` витрины

## 14. Безопасность и гигиена

- [ ] Секретов, токенов и `.env` в диффе нет — **CI** (secret scan)
- [ ] Нет PII в логах, URL, скриншотах тестов и фикстурах (телефоны вымышленные `+966 5X XXX XXXX`)
- [ ] Защищённые пути (`tokens.css`, `shared/api/ports`, `docs/product`, lock-файлы, CI, wrangler) не тронуты или изменение явно согласовано
- [ ] Новые зависимости обоснованы в описании PR, лицензия совместима

## 15. Ревью

- [ ] Независимое ревью субагентом `code-reviewer` против брифа и этого чек-листа выполнено, замечания закрыты
- [ ] Для изменений UI — `design-review` и `rtl-qa`; для текстов — `ux-copy-review`
- [ ] Автоматическое ревью Claude в GitHub (`claude-code-action`) без открытых блокирующих замечаний
- [ ] Ревью человеком, squash-merge в защищённый `main`

### Карта CI (для справки)

`install → typecheck → lint (ESLint + boundaries + rtl + i18n + no-hardcoded-strings) → unit + Storybook → build → e2e + axe + screenshots (ar, en) → size-limit → changeset check`
Ночью и на `main`: Lighthouse CI, полный визуальный прогон, dependency-cruiser граф.
Зеркальный `.gitlab-ci.yml` поддерживается в актуальном состоянии с первого дня.

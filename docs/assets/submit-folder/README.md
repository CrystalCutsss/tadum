# Папка с документами — анимация (наработка)

Анимированная папка: в неё по очереди влетают документы, папка закрывается, затем по кругу листы выглядывают и папка приоткрывается (пауза между циклами 1 с). Была над кнопкой «Send for review» в панели отправки документов, когда всё готово. Кирилл убрал её из панели 2026-11-12 и попросил сохранить код для будущего использования.

Код в этой папке не собирается и не проверяется: `docs/**` исключён из ESLint, TypeScript и сборки. Чтобы вернуть компонент, скопируйте файл обратно в `src`.

## Что здесь

- `submit-folder.tsx` — компонент `SubmitFolder({ className })`. Он декоративный (`aria-hidden`) и сам запускает анимацию при монтировании.

## Откуда взяты форма и движение

Это адаптация компонента «Folder» из React Bits (режим flap, вариант solid, ярлык справа). Исходник лежит в Drive, документ «Код для папки».

- **Геометрия.** Пропорции стенок 224 × 176, ярлык высотой 20, листы — 54 % ширины папки.
- **Расклад листов.** Веер листов `FLAP_REST`.
- **Движение.** Пружины пересчитаны в `stiffness` и `damping` для `motion/react`. Сценарий появления и тайминги взяты из исходника.

Лицензия React Bits — MIT + Commons Clause (A-063).

## Как вернуть

1. Скопируйте `submit-folder.tsx` в нужный срез, например `src/features/submit-documents/ui/`.
2. Нужна библиотека `motion` — она уже есть в `package.json`.
3. Цвета берутся из токенов `--folder-back`, `--folder-front`, `--folder-paper`. Токены и классы `bg-/fill-/stroke-folder-*` остались в `src/styles/tokens.css` и `globals.css`.
4. Размер задаётся шириной: `w-24` по умолчанию, `className="w-28"` на телефоне. Высота считается по пропорции 224 × 196.
5. Так папка стояла в панели отправки (`submit-bar.tsx`):
   - компьютер: обёртка `absolute inset-x-0 -top-15.5 md:-top-16.5 hidden sm:flex justify-center` в колонке кнопки;
   - телефон: обёртка `absolute inset-x-0 top-0 -translate-y-5/6 flex justify-center sm:hidden` в корне панели;
   - над панелью был распорка-`div` высотой `h-12` (на телефоне `h-20`), чтобы последняя карточка не уходила под папку.
6. При `prefers-reduced-motion` анимации нет, папка сразу в позе покоя.

Решения по папке записаны в `docs/decisions/assumptions.md` (A-065).

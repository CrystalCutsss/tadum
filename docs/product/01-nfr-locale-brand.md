### 1.3 Цифры, деньги, даты, телефоны

Единственная точка форматирования — `shared/i18n/format.ts`. Прямые вызовы `toLocaleString`, `Intl.*` и `Date` в компонентах запрещены линтером (`no-restricted-syntax`).

> **Важно (D-071).** `Intl` не даёт строки этой таблицы напрямую: в Node 22 `ar-SA` возвращает `<RLM>150,000 ر.س.<RLM>` (невидимые RLM и точка), `04<RLM>/11<RLM>/2026` (RLM), `en-US` — `11/04/2026` (месяц первым), относительное время — `قبل 3 أيام`, проценты — `28٪`. Поэтому `Intl` используется только для чисел (`en-US`, `maximumFractionDigits: 0`) и названий месяцев; деньги, даты (`DD/MM/YYYY` из `formatToParts` с `en-GB`), проценты, размеры файлов и относительное время собираются вручную и ключами i18n; символы U+200E (LRM) и U+200F (RLM) удаляются (в примерах выше они показаны как `<RLM>`, в реальном выводе невидимы). Тесты сравнивают с примерами ниже побайтно.

| Что | Правило | Пример AR | Пример EN | Решение |
|---|---|---|---|---|
| Цифры | Западные 0–9 в обоих языках: `numberingSystem: 'latn'` во всех `Intl`-вызовах; локаль форматирования `ar-SA-u-nu-latn` | 150,000 | 150,000 | требования |
| Разделители | Группы разрядов — запятая, десятичный — точка в обоих языках (так отдаёт `ar-SA-u-nu-latn`); суммы без копеек (халалы не показываем, `maximumFractionDigits: 0`), кроме случаев, когда бэкенд отдаёт дробное | 42,500 | 42,500 | D-006 |
| Валюта | Код и позиция зависят от языка: EN — `SAR 150,000` (код перед числом, неразрывный пробел); AR — `150,000 ر.س` (символ после числа). Символ ﷼ и новый знак SAR (SVG) не используются | 150,000 ر.س | SAR 150,000 | D-006 |
| Деньги в событиях аналитики | Не отправляются; только корзины (`amount_bucket`, `used_share_bucket`) | — | — | SC-06, SC-07 |
| Даты — календарь | Только григорианский; локаль `ar-SA-u-ca-gregory-nu-latn` (иначе движок подставит хиджру); хиджра не показывается нигде | — | — | D-005 |
| Даты — короткий формат | `DD/MM/YYYY` в обоих языках | 04/11/2026 | 04/11/2026 | D-053 |
| Даты — длинный формат | Только на экране статуса / в раскрытых карточках: число + название месяца + год на языке интерфейса | 4 نوفمبر 2026 | 4 November 2026 | D-053 |
| Время | 24-часовой формат `HH:mm`; часовой пояс всегда `Asia/Riyadh` независимо от устройства | 14:30 | 14:30 | требования |
| Относительное время | `Intl.RelativeTimeFormat` для «обновлено 3 дня назад» / «منذ 3 أيام»; после 7 дней — короткая дата | منذ 3 أيام | 3 days ago | SC-03 (D-030) |
| Телефон | Отображение `+966 5X XXX XXXX` (группы 3-3-4 после кода страны), всегда LTR; маскирование на экране OTP: `+966 5• ••• •812` (последние 3 цифры). Нормализация — вне фронтенда (D-013); фронтенд валидирует только формат `+9665XXXXXXXX` | +966 50 123 4567 | +966 50 123 4567 | D-013, D-021 |
| Проценты | Западные цифры, знак `%` после числа с неразрывным пробелом в AR (`28 %`) и без в EN (`28%`) | 28 % | 28% | SC-07 |
| Размеры файлов | МБ/КБ по языку: `10 ميجابايت` / `10 MB`; порог — двоичные МБ не используем, 1 МБ = 1 000 000 байт для отображения, лимит 10 МБ проверяется как 10 × 1024 × 1024 | 10 ميجابايت | 10 MB | SC-02 |

### 1.4 Множественное число и длина текста

| Правило | Значение | Проверка |
|---|---|---|
| Формы множественного числа | JSON v4 i18next; для каждого ключа с `count` в `ar` — все шесть форм (`zero`, `one`, `two`, `few`, `many`, `other`), в `en` — `one`, `other` | `i18next-parser --fail-on-warnings` (**CI**) + unit-тест, перебирающий `count ∈ {0,1,2,3,11,100}` |
| Паритет ключей | Каждый ключ есть в `ar` и `en`; пустые значения запрещены; порядок ключей в файлах — алфавитный | **CI** |
| Длина текста | Арабский в среднем на 20–25 % длиннее английского по ширине при той же кегле; макеты проверяются на самой длинной строке из двух языков, кнопки — на 360 px без переноса на третью строку; у заголовков `line-clamp` не ставим (лучше перенос) | скриншоты 360 px AR/EN (**CI**), Storybook-история «longest strings» |
| Строки в коде | Ни одной пользовательской строки вне `shared/i18n/locales/*.json`; `aria-label`, `title`, `placeholder`, тексты ошибок — тоже через ключи | lint `i18next/no-literal-string` (**CI**) |
| Интерполяция | Только именованные плейсхолдеры в одинарных фигурных скобках `{count}`, `{amount}`, `{company}` — i18next настроен на `prefix: '{'`, `suffix: '}'` (D-075); значения форматируются до подстановки (`formatMoney` и т. п.); HTML в строках запрещён, выделения — через `<Trans>` с нумерованными компонентами | lint + unit |

### 2.2 Производительность

| Заголовки и CSP | Cloudflare Worker отдаёт `Content-Security-Policy` (self + домен аналитики + `wa.me` для ссылок), `X-Content-Type-Options`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` (камера только для загрузки файлов, если понадобится) | `wrangler.toml` / `_headers`, проверка в CI запросом |
| Внешние ссылки | `target="_blank" rel="noopener noreferrer"`; домены разрешённых внешних ссылок — список в `shared/config/external-links.ts` (Sadq, Nafith, `wa.me`, лендинг) | lint |
| Файлы | Проверка типа по сигнатуре (magic bytes), не только по расширению; размер до 10 МБ; имена файлов не показываем целиком (обрезка посередине) и не отправляем в аналитику | unit |
| Зависимости | `pnpm audit` без high/critical; lock-файл защищён от правок агентом без согласования | **CI** |
| Приватность и согласие | Аналитика без PII, IP-анонимизация, без записей сессий (session replay) в MVP; баннер согласия на cookies не показываем (D-055); пункт «пересмотреть с юристом (PDPL)» — в чек-лист выхода в прод | чек-лист релиза в прод |

### 2.5 Встроенный браузер WhatsApp (IAB) и PWA

| Правило | Значение | Проверка |
|---|---|---|
| Детекция IAB | По user-agent (`WhatsApp`) с запасным признаком (нет `navigator.share` + Android WebView); утилита `isInAppBrowser()` в `shared/lib/env` | unit |
| Скачивание файлов в IAB | Только прямые URL с `Content-Disposition: attachment` или `<a download href="data:…">`; `blob:`-ссылки и `window.open` после `await` не используются; для изображений (QR) — режим «удерживайте, чтобы сохранить» | SC-10, SP-02, DoD |
| Внешние ссылки в IAB | Sadq/Nafith могут не открыться — всегда есть «Скопировать ссылку» и подсказка «откройте в браузере» (`common.open_in_browser`) | SC-06 A6 |
| Хранилище IAB | Отдельное от Safari/Chrome: сессия и язык могут не переноситься между IAB и браузером — это ожидаемо, не ошибка; при переходе «открыть в браузере» пользователь входит заново (`returnTo` сохраняется в URL) | ручная проверка |
| PWA — установка | Манифест: `name: "Tadum"`, `short_name: "Tadum"`, `lang: "ar"`, `dir: "rtl"`, `display: "standalone"`, `start_url` с базовым путём версии (`/p/tadum/vN/` на витрине, `/` в проде), иконки `any` + `maskable` 192/512, `apple-touch-icon` 180; `theme_color` — из токенов обеих тем через `<meta media>` | Lighthouse PWA-проверки |
| PWA — iOS | Нет `beforeinstallprompt`: карточка в настройках показывает инструкцию «Поделиться → На экран “Домой”»; карточка только в `/c/help`, `/s/help` (SC-10, SC10-2) | Storybook |
| PWA — обновления | `generateSW`, `registerType: 'autoUpdate'`; тихое обновление, тост «Доступна новая версия» только при `major` (D-024); версия приложения из `package.json` показана в настройках | — |
| PWA — офлайн | Только состояние «нет сети» на каждом экране (`common.offline`), последние данные из кэша с подписью `common.cached_at`; офлайн-работа (очередь действий) — нет; внешние ссылки и загрузка файлов офлайн недоступны с подсказкой | SC-10 |
| Прекэш | Оболочка, шрифты обоих языков, иконки; данные — `NetworkFirst` для будущего `/api/`, в моке — память + `localStorage` | конфиг `vite-plugin-pwa` |
| Хранилище WebKit | Данные сайта могут быть удалены после 7 дней без использования — локальные данные считаем кэшем; ничего невосстановимого в `localStorage` нет | ADR |

### 2.6 Надёжность, данные, наблюдаемость

| Правило | Значение | Проверка |
|---|---|---|
| Состояния каждого экрана | `loading` (скелетон), `empty`, `error` с «Повторить», `offline`, `blocked` (по правам), `normal` — все реализованы и есть в Storybook в AR и EN | DoD, Storybook-тесты (**CI**) |
| Повторы | Запросы чтения — до 2 повторов с экспоненциальной задержкой (TanStack Query); мутации — без автоповтора, кнопка «Повторить» | конфиг `queryClient` |

| Несогласованные данные | UI не падает: `data_inconsistency {kind}` в аналитику и нейтральное отображение (SC-07 A3, SP-01 A7) | unit на `derive*` |
| Валидация данных | Все ответы портов проходят Zod-схемы из `01-entities.md`; ошибка схемы = состояние `error`, не падение | unit |
| Файлы | PDF / JPG / PNG до 10 МБ, прогресс загрузки, отмена, повтор после обрыва сети (очередь в памяти) | SC-02 |

| Логи | В проде `console.*` вырезаются; отладочные логи — через `debug`-флаг демо-панели | сборка |
| Версионирование | Conventional Commits + Changesets; версия и хеш сборки — в настройках и в событии `app_loaded` | **CI** |

### 3.4 Голос и тон

Голос Tadum — **персональный менеджер**: спокойный, уважительный, конкретный. Он объясняет, что происходит и что делать дальше, не давит, не обещает лишнего и не прячется за канцеляритом.

| Принцип | Значит | Делаем | Не делаем |
|---|---|---|---|
| Одна мысль на экран | У экрана один заголовок и одно главное действие | «Загрузите недостающие документы» + кнопка | Три призыва, баннер и тост одновременно |
| Коротко | Заголовок ≤ 6 слов, абзац ≤ 2 предложений, кнопка — глагол + объект (≤ 3 слов) | «Отправить на проверку» | «Нажмите здесь, чтобы отправить ваши документы на проверку» |
| Честно про сроки | Срок называем только когда он пришёл из данных (`meta.hours`, D-033); иначе — без срока | «Проверяем документы» | «Ответим в течение часа», «мгновенно», «быстро» |
| На чьей стороне шаг | Каждый статусный текст говорит, кто действует: вы / мы / никто (D-008, §6 структуры кабинета) | «Мы проверяем…», «Вам нужно…» | Безличное «идёт проверка» |
| Без давления | Нет срочности, таймеров обратного отсчёта (кроме OTP), восклицательных знаков, капса | «Когда будете готовы — отправьте» | «Успейте сегодня!» |
| Без вины | Отклонение — про файл, не про человека | «Этот файл не подошёл: нужна выписка за 6 месяцев» | «Вы загрузили неправильный документ» |
| Уважительно | Арабский — формальный MSA, обращение к одному человеку во 2-м лице единственного числа в уважительном регистре; множественное أنتم / -كم не используется (D-009, D-051); английский — «you», без сленга | «ارفع مستنداتك» | Диалект, «يا صديقي», «ارفعوا مستنداتكم», «Hey there!» |
| Нейтрально к третьим сторонам | Sadq, Nafith, ZATCA, SPL, WhatsApp, Molim, SIMAH — только текстом, без логотипов, скриншотов и оценок | «Подпишите в Sadq» | Логотип Sadq на кнопке |
| Без финансового жаргона | Нет «кредит / заём / финансирование / процент / BNPL / рассрочка под %»; есть «торговый лимит», «платите частями», «Tadum покупает товар у вашего поставщика» | см. глоссарий §1.5 | «Ваш кредитный лимит одобрен» |
| Без эмодзи | В интерфейсе и в предзаполненных текстах WhatsApp эмодзи нет | — | ✅🎉 |

### 3.5 Формулы текстов по типам

| Тип | Формула | Пример EN | Пример AR |
|---|---|---|---|
| Ошибка (любая) | **что произошло → что сделать → куда обратиться** (третья часть — SupportBar, в тексте не дублируется, если он виден на экране) | We couldn't upload the file. Check your connection and try again | تعذّر رفع الملف. تحقّق من الاتصال وحاول مرة أخرى |
| Отклонённый документ | что не подошло (из тега UW) → что загрузить | This file didn't work: we need the last 6 months. Upload a new statement | لم يُقبل هذا الملف: نحتاج آخر 6 أشهر. ارفع كشفًا جديدًا |
| Статус «на нашей стороне» | мы + что делаем (+ срок, только из данных) | We're reviewing your documents | نراجع مستنداتك |
| Статус «на вашей стороне» | глагол действия + объект + зачем (опционально) | Sign the documents to activate your limit | وقّع المستندات لتفعيل حدّك |
| Статус «ничего не нужно» | факт + что дальше (без восторга) | Your first purchase is complete. You can keep buying the same way | اكتملت عمليتك الأولى. يمكنك مواصلة الشراء بالطريقة نفسها |
| Пустое состояние | что здесь будет → как это появится → действие (если есть) | No clients yet. Share your link — clients who apply through it will appear here | لا عملاء بعد. شارك رابطك — سيظهر هنا من يتقدّم عبره |
| Закрытие / отказ | нейтральный факт без причины и без вины → путь в поддержку | Your application is closed. Our team can tell you more | تم إغلاق طلبك. يمكن لفريقنا توضيح المزيد |
| Подтверждение (единственный диалог — выход, SC-10) | вопрос + последствие в одной строке → две кнопки: действие / «Остаться» | Log out? You'll need a new code next time | تسجيل الخروج؟ ستحتاج إلى رمز جديد في المرة القادمة |
| Тост | ≤ 1 предложение, факт, без «успешно» | Documents sent for review | تم إرسال المستندات للمراجعة |
| Кнопка | глагол + объект; «Отмена» → «Остаться» / «Назад» по смыслу | Send for review | إرسال للمراجعة |
| Подсказка под полем | что ввести и в каком виде, без «пожалуйста» | +966 5X XXX XXXX | +966 5X XXX XXXX |
| Предзаполненный текст WhatsApp | приветствие → намерение → данные; на языке интерфейса (D-046) | Hello, I'd like to make a purchase through Tadum for {company}. Here is the quotation: | مرحبًا، أرغب في إجراء عملية شراء عبر تدوم لشركة {company}. إليكم عرض السعر: |

### 3.6 Лексикон и его проверка

`tov-lexicon.json` — машиночитаемая версия §1.5 и §3.4: запрещённые слова и шаблоны (с регулярными выражениями для `en` и `ar`), разрешённые термины, третьи стороны, формулы и исключения по ключам. Используется тремя потребителями:

1. **Lint текстов** `scripts/lint-i18n-tov.mjs` — прогоняется в CI по `shared/i18n/locales/*.json`: `error` блокирует merge, `warn` — комментарий в PR. Исключение задаётся в лексиконе (`exceptions`), а не в коде.
2. **Скилл `ux-writer`** — читает лексикон перед написанием ключей, проверяет формулы §3.5, ведёт глоссарий.
3. **Ревьюер текстов (человек)** — таблицы §6 брифов и сценариев проверяются по тем же правилам; лексикон — единственный источник списка.

Правила ведения: изменение лексикона — отдельный коммит с объяснением; добавление слова в `forbidden` требует указания замены (`replace_with`); снятие запрета — решение в журнале (D-###).

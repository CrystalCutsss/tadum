# Roadmap прототипа — Tadum

**Версия:** 1.1 (черновик — живой каркас) · **Дата:** 2026-11-04 · **Статус:** порядок версий утверждён планом (§2.2); вопросы закрыты (D-060, D-061); состав каждой версии уточняется брифами фич.
**Источники:** план §2.2 (приоритеты MVP и порядок сборки), §3.4 (витрина), `01-cabinet-structure.md` §1 (колонка «Версия»), сценарии `SC-*`/`SP-*` (строка «Версия прототипа»), `04-metrics-and-events.md` (колонка «v»). **Связанные документы:** `05-master-prompt.md` (будет), release notes `06 Версии прототипа/vN.md`.

> Одна версия = одна публикация на витрине Proto как `/p/tadum/vN/` (D-018, D-019) с собственным `scope` PWA и release notes. Версии накопительные: v3 содержит всё из v1–v2. Внутри версии фичи идут брифами `TD-###`; порядок внутри версии — на усмотрение, порядок версий — фиксированный. Сроков нет (план: «сроки не критичны»), есть критерии готовности.

## 2. Версии

### v1 — каркас

**Цель:** проверить архитектуру, RTL, дизайн-систему и процесс публикации на самом простом наборе экранов; команда видит «скелет» раньше деталей.

| Что входит | Сценарии | Маршруты |
|---|---|---|
| Скелет репозитория по мастер-промпту: Vite + React 19 + TanStack Router/Query, shadcn (Radix, `rtl: true`), Tailwind v4, react-i18next, Storybook, Playwright, CI с DoD-проверками, `release:proto` | — | — |
| Дизайн-система на пресете shadcn, который Кирилл задаёт заранее (D-077): токены пресета + семантические токены Tadum, фиксация в `02-design-system.md` | — | — |
| Вход по OTP (мок, D-021, D-027), выход с подтверждением, истечение сессии, 404 | SC-01, SC-10 | `/`, `/login`, `/login/code`, `/session-expired`, `*` |
| Оболочка: шапка с названием компании, переключатель языка (AR по умолчанию, `?lang=`), тема по системе + переключатель в настройках (D-025), SupportBar, нижняя навигация, демо-панель с персонами и сетью | SC-10 | `/c/help` |
| «Заявка не найдена» для неизвестного номера (SC-01 A8) и заглушки следующих версий: `/c/documents` («в v2»), `/s/home` и `/s/help` («в v3»; поставщики без клиентской роли попадают сюда) (D-067) | SC-01 A8 | `/not-found`, `/c/documents`, `/s/home`, `/s/help` |
| Главная клиента: шкала прогресса и карточка следующего шага для всех `client_status` (без блоков лимита), тост + баннер смены статуса (D-034), опрос статуса (D-035) | SC-05 (состояние на `home`) | `/c/home` |

| Аналитика: `track()`, `ConsoleProvider`, `DemoPanelProvider`, события v1 из словаря | — | — |

**Готово, когда:** все экраны v1 проходят DoD; скриншоты 360/768/1280 × AR/EN × light/dark в CI; персоны `client_new … client_closed_lost` переключаются из демо-панели и меняют шкалу; `pnpm release:proto v1` публикует на витрину с отдельным паролем; release notes `v1.md` в Drive.

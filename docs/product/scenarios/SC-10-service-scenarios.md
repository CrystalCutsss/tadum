## 1. Сценарии

### 1.1 Смена языка

```
Дано:  любой экран, язык ar
Когда: пользователь нажимает переключатель языка в шапке и выбирает English
Тогда: без перезагрузки: <html lang="en" dir="ltr">, DirectionProvider ltr, шрифт Geist (D-004);
       все тексты, форматы денег/дат (D-005, D-006), порядок шкалы и иконки-стрелки обновляются;
       позиция в приложении и введённые данные (например, номер телефона в поле) сохраняются;
       выбор записан в хранилище; событие language_changed {to: en, source: switch}

Дано:  пользователь открыл ссылку с ?lang=ar при сохранённом en
Тогда: применяется ar (URL сильнее сохранённого), параметр убирается из URL
```

### 1.2 Выход

```
Дано:  любой экран с сессией
Когда: пользователь выбирает «Выйти» в меню / на экране помощи
Тогда: сессия и returnTo удалены; язык и тема сохранены; редирект на /login;
       событие logout {screen_id}
Когда: после выхода нажата «Назад» в браузере
Тогда: защищённые маршруты снова ведут на /login (нет кэшированных экранов с данными)
```

### 1.3 Сохранение сессии

```
Дано:  пользователь вошёл
Когда: перезагружает страницу / открывает кабинет в новой вкладке / закрывает и открывает браузер
Тогда: сессия на месте (30 дней, D-007), открывается тот же маршрут или home активной роли;
       язык и тема прежние
Когда: выход выполнен в одной вкладке
Тогда: другие вкладки при следующем действии получают 401 → /session-expired → вход заново
```

### 1.4 Сессия истекла

```
Дано:  прошло 30 дней или бэкенд вернул 401 (мок: expireSession())
Когда: пользователь открывает кабинет или выполняет действие
Тогда: редирект на /session-expired с текстом «для безопасности войдите снова»; returnTo сохранён;
       после входа — возврат на исходный маршрут; событие session_expired {last_screen_id}
Дано:  истечение произошло во время загрузки файла
Тогда: загрузка прерывается с upload.error.session, файл не теряется локально до перехода на вход
```

### 1.5 Тема

```
Дано:  первый вход, тема не выбиралась
Тогда: тема светлая, даже если в системе тёмная (D-079), без вспышки неправильной темы при загрузке
Когда: пользователь в настройках (/c/help или /s/help) выбирает «Светлая» / «Тёмная» / «Как в системе»
Тогда: применяется немедленно, сохраняется рядом с языком; событие theme_changed {to}
```

### 1.6 Офлайн

```
Дано:  пользователь в кабинете, пропала сеть (мок: setNetwork('offline'))
Тогда: баннер common.offline_banner над контентом; экраны из кэша читаются; действия загрузки/отправки
       задизейблены с подсказкой; внешние ссылки (WhatsApp, Sadq/Nafith) остаются кликабельными
Когда: сеть вернулась
Тогда: баннер исчезает, данные перезапрашиваются, событие network_restored {offline_seconds}
```

### 1.7 Установка PWA

```
Дано:  Android Chrome, критерии установки выполнены
Когда: браузер даёт beforeinstallprompt
Тогда: ненавязчивая карточка pwa.install_card в /c/help (не всплывающее окно) с кнопкой «Установить»;
       событие pwa_install_prompted / pwa_installed
Дано:  iOS Safari
Тогда: карточка с инструкцией pwa.ios_instruction («Поделиться → На экран “Домой”»), без кнопки
Дано:  встроенный браузер WhatsApp
Тогда: карточка pwa.open_in_browser_hint («откройте в браузере, чтобы установить»)
```

### 1.8 Неизвестный маршрут и ошибка загрузки

```
Когда: открыт несуществующий путь
Тогда: system.404 с кнопкой «На главную» (home активной роли или /login)
Когда: данные маршрута не загрузились (ошибка сервера)
Тогда: карточка common.load_error с «Повторить» и SupportBar; оболочка остаётся
```

## 5. События аналитики

| Событие | Когда | Свойства |
|---|---|---|
| `language_changed` | смена языка | `{ to, source: 'switch' \| 'url' }` |
| `theme_changed` | смена темы в настройках | `{ to: 'system' \| 'light' \| 'dark' }` |
| `logout` | выход | `{ screen_id, offline }` |
| `session_expired` | показан `auth.expired` | `{ last_screen_id, reason?: 'ttl' \| '401' \| 'storage_evicted' }` |
| `network_offline` / `network_restored` | смена состояния сети | `{ offline_seconds? }` |
| `pwa_install_prompted` / `pwa_installed` / `pwa_update_prompted` | PWA | `{ platform: 'android' \| 'ios' \| 'desktop', in_iab }` |
| `storage_unavailable` | A3 | `{}` |
| `screen_viewed` | `system.404` | `{ screen_id: 'system.404', path_hash }` — путь хэшируется, чтобы не утекли параметры |

Отдельно фиксируем `display_mode` (`standalone` / `browser`) и `in_iab` как свойства всех событий на уровне слоя аналитики — для метрики установок и отладки WhatsApp-браузера.

## 6. Критерии приёмки

- [ ] Смена языка не перезагружает страницу и не теряет состояние форм и загрузок; направление, шрифт, форматы и зеркалирование обновляются сразу.
- [ ] `?lang=` сильнее сохранённого выбора и убирается из URL.
- [ ] Выход очищает сессию и `returnTo`, сохраняет язык и тему; «Назад» после выхода не показывает данные.
- [ ] Сессия переживает перезагрузку, новую вкладку и перезапуск браузера; истечение (TTL или 401) ведёт на `auth.expired` с возвратом на исходный маршрут после входа.
- [ ] Тема по умолчанию следует системной без вспышки; ручной выбор только в настройках (D-025).
- [ ] Офлайн: баннер, чтение из кэша, отключённые действия, внешние ссылки работают; восстановление сети перезапрашивает данные.
- [ ] PWA: четыре варианта карточки установки по платформе; тихое обновление, тост только при `major` (D-024).
- [ ] 404 и ошибка загрузки — нейтральные экраны внутри оболочки.
- [ ] Тексты в `ar` и `en`; axe без нарушений; переключатели языка и темы — кнопки с подписями, не только иконки.
- [ ] Storybook: `AppHeader` (ar/en, dual/single), `HelpScreen` (все карточки PWA), `OfflineBanner`, `auth.expired`, `system.404` × AR/EN × light/dark.
- [ ] Playwright: смена языка на `/c/documents` с частично заполненной загрузкой; выход и «Назад»; `expireSession` с `returnTo`; `setNetwork('offline')` на `/c/home`; 404.

## 7. Заметки для реализации

- Язык и тема хранятся в одном объекте настроек (`localStorage`), сессия — отдельно; все чтения/записи обёрнуты в try/catch (A3).
- Тема применяется инлайн-скриптом в `<head>` до рендера, чтобы избежать вспышки.
- Детекция IAB — по user-agent (WhatsApp) с запасным путём; детекция установки — `display-mode: standalone` и `appinstalled`.
- Версия приложения в настройках — из `package.json` на этапе сборки; на витрине совпадает с `vN`.

## 8. Открытые вопросы

Решено (Кирилл, 2026-11-04):

- **SC10-1** — диалог подтверждения при выходе нужен: единственный диалог в служебных сценариях (выход = потеря 30-дневной сессии, D-007).
- **SC10-2** — карточка установки PWA только в настройках в MVP; на `home` — не раньше v5 и только по данным аналитики (`pwa_install_prompt_shown` / `pwa_installed`).

Открытых вопросов по сценарию нет.

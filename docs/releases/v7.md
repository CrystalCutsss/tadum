# Tadum v7 — новая карточка документа

Выпуск по правкам экрана документов клиента (решения Кирилла 2026-11-10). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Карточка документа больше не сворачивается, зоны перетаскивания нет: загрузка — кнопкой «Upload» у правого края карточки
- Под карточкой — серая панель: загруженный файл (имя и размер), под ним сообщения об ошибках, затем «How to get it» и «See an example» слева и ссылки на сервисы справа
- «Why this file didn't work» и ошибки загрузки — под загруженным файлом: белый блок, иконка в оранжевом квадрате
- На телефоне кнопки панели идут в один ряд с горизонтальной прокруткой
- Бейдж «Uploaded» зелёный, с простой галочкой; у «Approved» — галочка в круге
- Панель «Steps» в том же сером цвете, что и панель под карточкой, отступы компактнее
- На компьютере прокручивается только область контента; при оттягивании страницы вокруг неё остаётся цвет сайдбара

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка; экран документов открывается пунктом «Documents» в сайдбаре
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Тексты на арабском и английском ждут проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Оттягивание страницы в Safari до выпуска не проверялось (только Chromium)
- Кнопки в панели под карточкой — 32 px (решение Кирилла 2026-11-10), меньше прежних 44 px
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v7/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Клиент: новая заявка», «Клиент: нужен новый файл» или «Клиент: дозапрос документов», затем «Documents» в сайдбаре
- Язык и тема — кнопками в шапке кабинета

## Что проверить команде

- Нужен новый файл: под старым файлом видна причина, после загрузки нового файла статус меняется
- Новая заявка: загрузить файл — он появляется в серой панели под карточкой, бейдж «Uploaded» зелёный
- Телефон: кнопки панели в один ряд, ссылки на сервисы — прокруткой; арабский — всё зеркально
- Компьютер: прокрутить и оттянуть страницу в Safari и Chrome — вокруг области контента нет белых полос

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v7 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v6 не затрагиваются.

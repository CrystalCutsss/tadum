# Tadum v10 — код страны внутри поля номера

Правка экрана входа (решение Кирилла 2026-11-11). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Код страны «+966» — внутри поля номера слева, поле номера во всю ширину, как кнопка «Get code» под ним
- Номер по-прежнему вводится слева направо и в арабском, и в английском интерфейсе; клик по «+966» ставит курсор в поле

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка; экран документов открывается пунктом «Documents» в сайдбаре
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Часть текстов на арабском и английском ждёт проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Код для любой персоны — `0000`; неверный код для проверки ошибок — например, `1234`
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v10/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Вход по номеру»
- Номер `50 000 0001` (новая заявка), затем код `0000`

## Что проверить команде

- Поле номера одной ширины с кнопкой, «+966» внутри поля слева — в арабском и английском, в светлой и тёмной теме
- Номер не с 5 — поле подсвечено красным, подсказка под полем

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v10 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v9 не затрагиваются.

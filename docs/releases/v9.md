# Tadum v9 — новый вход по номеру

Выпуск по редизайну экранов входа (решения Кирилла 2026-11-10). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Экраны входа по номеру и по коду собраны по блоку shadcn login-05: логотип «tadum.» вверху страницы, форма по центру, заголовок «Welcome to Tadum»
- Код вводится в одно поле вместо четырёх ячеек: после 4-й цифры отправляется сам, принимает вставку целиком, в том числе с лишним текстом («Code: 12 34»), и арабские цифры
- Поля и кнопки крупнее, со скруглением как у кнопок экрана документов
- Во время запроса — индикатор загрузки: в кнопке «Get code», под полем кода, в кнопке «Send a new code»
- Внизу страницы — переключатели языка и темы, как в шапке кабинета
- Все ошибки входа на месте: неверный номер, слишком много запросов, неверный и истёкший код, 5 попыток, нет сети, ошибка сервера, номер без заявки
- Обратный отсчёт «слишком много запросов» больше не показывает на минуту больше сразу после ошибки

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка; экран документов открывается пунктом «Documents» в сайдбаре
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Часть текстов на арабском и английском ждёт проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Код для любой персоны — `0000`; неверный код для проверки ошибок — например, `1234`
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v9/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Вход по номеру»
- Номер `5X XXX XXXX` любой персоны, например `50 000 0001` (новая заявка), затем код `0000`
- Язык и тема — кнопками внизу экрана входа и в шапке кабинета

## Что проверить команде

- Вход: ввести номер, получить код, ввести `0000` — открывается кабинет
- Ошибки: номер не с 5 — подсказка под полем; код `1234` — поле очищается, текст ошибки под полем
- Вставка кода из буфера целиком — отправляется без кнопки «Confirm»
- Арабский и английский, светлая и тёмная тема; на телефоне — поле и кнопка не уходят за экран

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v9 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v8 не затрагиваются.

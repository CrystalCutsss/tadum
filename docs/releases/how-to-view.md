# Как смотреть Tadum на витрине

1. Откройте https://proto.kirillgloba.workers.dev — введите общий пароль витрины.
2. Откройте карточку **Tadum** (или сразу https://proto.kirillgloba.workers.dev/p/tadum/) — введите пароль Tadum. Пароли выдаёт Кирилл; в чатах и документах их не пишем.
3. На компьютере прототип показан в рамке телефона; на телефоне — на весь экран. Внизу меню:
   - **Персона** — какой пользователь вошёл и в каком состоянии его заявка; «Вход по номеру» — начать с экрана входа;
   - **Язык** — العربية (справа налево) или English;
   - **Версия** — v1, v2, …
4. Внутри прототипа кнопка **Демо** открывает демо-панель: смена персоны, действия команды Tadum (одобрить документ, сменить статус, истечь сессию), режим сети, лента событий.
5. Вход вручную: номер `500000001`…`500000014` (по персонам — таблица в `README.md`), код всегда `0000`.

Данные вымышленные и живут только в вашем браузере. Чтобы начать сценарий заново, выберите персону ещё раз.

Ссылкой на конкретное состояние можно поделиться: `https://proto.kirillgloba.workers.dev/p/tadum/v1/?persona=client_active&lang=en` (получателю всё равно понадобятся оба пароля).

# Tadum v6 — экран документов клиента

Выпуск по сценариям SC-02…SC-04 и решениям Кирилла 2026-11-09 (D-078, A-058). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Экран «Your application» (пункт «Documents»): все документы заявки списком, у каждого — описание, видео «How to get it», пример и ссылки на сервисы, где его получить
- Загрузка в строке документа: камера, галерея или файл (на телефоне — шторка, на компьютере — окно и перетаскивание); один файл на документ, замена — с подтверждением
- Нижняя карточка отправки с прогрессом; если чего-то не хватает — подсказка, подсветка и прокрутка к первому недостающему документу
- «Нужен новый файл»: причина прямо в строке и загрузка нового файла
- Второй раунд (дозапрос): баннер «Almost there», панель «Steps» — «Documents» пройдены, «Review» в процессе
- После отправки — только просмотр и панель шагов заявки (на компьютере — справа, на телефоне — сверху)
- В меню витрины вернулись клиентские сценарии: новая заявка, нужен новый файл, дозапрос документов; пункт «Поставщик» пока убран
- Хлебные крошки в шапке скрыты, пока у страниц нет вложенных

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка; экран документов открывается пунктом «Documents» в сайдбаре
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Тексты на арабском и английском ждут проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Видео открывается встроенным плеером Google Drive: без доступа к Google он не загрузится
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v6/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Клиент: новая заявка», «Клиент: нужен новый файл» или «Клиент: дозапрос документов», затем «Documents» в сайдбаре
- Комплект на проверке — «Вход по номеру», номер `500000004`, код `0000`
- Кабинет поставщика — «Клиент и поставщик» (роль переключается в аккаунте) или «Вход по номеру», номер `500000012`
- Язык и тема — кнопками в шапке кабинета

## Что проверить команде

- Новая заявка: загрузить файл камерой, из галереи и из файлов; попробовать отправить, не загрузив всё — подсветка и прокрутка к недостающему
- Нужен новый файл: причина видна в строке, после загрузки строка меняет статус
- Дозапрос: баннер «Almost there», в панели «Steps» шаг «Review» — «In progress»
- Телефон: строки раскрыты, без перетаскивания, выбор источника — шторкой; арабский — всё зеркально

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v6 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v5 не затрагиваются.

# Tadum v14 — код в четырёх ячейках с анимацией

Правка экрана кода при входе (решение Кирилла 2026-11-11). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Код из SMS или WhatsApp вводится в четыре ячейки: цифра пружинно встаёт в ячейку, каретка скользит к следующей, при вставке ячейки заполняются каскадом
- Неверный код — ячейки «осушаются» справа налево, рамки краснеют, курсор возвращается в первую ячейку
- Верный код — ряд заливается синим с галочкой, затем открывается кабинет
- Вставка кода целиком, в том числе с лишним текстом, и арабские цифры по-прежнему принимаются; при настройке «уменьшить движение» анимации нет

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Часть текстов на арабском и английском ждёт проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Код для любой персоны — `0000`; неверный код для проверки ошибок — например, `1234`
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v14/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Вход по номеру»
- Номер `50 000 0001` (новая заявка), затем код `0000` — анимация успеха; код `1234` — анимация ошибки

## Что проверить команде

- Набор цифр по одной и вставка кода целиком — анимация плавная, автоотправка после 4-й цифры
- Неверный код, затем верный — ячейки очищаются, повторный ввод работает
- Арабский и английский, светлая и тёмная тема; на телефоне ряд ячеек не выходит за экран

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v14 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v13 не затрагиваются.

# Tadum v11 — заявка клиента: номер CR, несколько файлов, замечания

Выпуск по экрану заявки клиента (решения Кирилла 2026-11-10 и 2026-11-11). Данные — мок с персонами, бэкенда нет.

## Что вошло

- Пункт меню «Application» вместо «Documents»; над документами — поле номера CR (10 цифр, обязательно для отправки), текст ошибки появляется под полем только при ошибке
- В документ можно загрузить до 10 файлов, кнопка «Add another file»; тот же файл повторно не загружается — окно-предупреждение
- Замечание ко всему документу и к отдельному файлу — оранжевая точка с мягкой пульсацией и оранжевый текст
- Кнопки «Get it on ZATCA / Molim / SIMAH» — в одном ряду с видео и примером
- Когда всё загружено, панель отправки вырастает с лёгким отскоком, появляется текст «Everything is ready», по обводке бежит синяя подсветка; удаление файла или ошибка возвращает панель обратно
- Комплект уходит на проверку только по кнопке «Send for review» — автоотправки нет (D-080)
- Тема по умолчанию — светлая, даже при тёмной теме устройства (D-079)
- Заставка загрузки — логотип «tadum.» с бегущим бликом; кнопка WhatsApp темнее; длинное название компании в меню уходит в фейд
- На этапе проверки блока CR нет; вверху — общий текст о дозапросе и ошибках

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Метод сохранения CR в `HttpAdapter` — заглушка до бэкенда (контракт — `docs/05-backend-contract.md`)
- Часть текстов на арабском и английском ждёт проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Код для любой персоны — `0000`
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v11/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Клиент: новая заявка»: поле CR, ошибка на весь документ (выписка) и ошибка файла (удостоверение)
- «Клиент: нужен новый файл» и «Клиент: дозапрос документов» — замечания к документу и к файлам на этапе проверки

## Что проверить команде

- Ввод CR: буквы не вводятся, арабские цифры превращаются в латинские, меньше 10 цифр — ошибка под полем
- Загрузить все документы и ввести CR — панель «Everything is ready» с подсветкой обводки; удалить файл — панель возвращается
- Загрузить тот же файл повторно — окно-предупреждение; 11-й файл в документ — сообщение о лимите
- Открыть в браузере с тёмной системной темой — интерфейс светлый

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v11 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v10 не затрагиваются.

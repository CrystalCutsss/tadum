# Tadum v12 — кнопки входа одной высоты

Правка экранов входа (решение Кирилла 2026-11-11). Данные — мок с персонами, бэкенда нет.

## Что вошло

- На экранах входа все кнопки, кроме «Change number», одной высоты 48 px и во всю ширину: «Get code», «Confirm», «Try again», «Send a new code», «Contact support», «Apply now» и «Sign in»
- Серые кнопки «Try again» и «Contact support» — без обводки

## Что отложено

- Раздел «Отправлено ранее» (файлы прошлых раундов) — нужен новый метод API
- Главная клиента пока заглушка
- Видео и пример — образцы-заглушки до материалов upload-портала; видео только на арабском
- Часть текстов на арабском и английском ждёт проверки носителем (`docs/i18n/needs-review.md`)

## Известные ограничения

- Мок хранит состояние в браузере: выбор сценария в меню начинает его с исходных данных
- Код для любой персоны — `0000`; неверный код для проверки ошибок — например, `1234`
- Проверка во встроенном браузере WhatsApp не проводилась

## Как смотреть

- Ссылка: https://proto.kirillgloba.workers.dev/p/tadum/v12/ — нужны два пароля: общий пароль витрины и отдельный пароль Tadum (у Кирилла)
- Меню в правом нижнем углу → «Сценарии и роли» → «Вход по номеру»
- Номер `50 000 0001` (новая заявка), затем код `0000`

## Что проверить команде

- Экран номера и экран кода: кнопки одной высоты; при ошибке сервера «Try again» и «Contact support» серые, без обводки
- Номер без заявки (`50 000 0014`, код `0000`) — «Apply now» и «Contact support» той же высоты

## Откат

Витрина собирается из `main` Proto: откат — revert публикации v12 в Proto (или Rollback в дашборде Cloudflare Workers). v1–v11 не затрагиваются.

# Допущения

Формат: что · почему · как проверить.

- **A-001.** Команда пресета shadcn приходит с `--template vite`, а §1.2 и 4a.1 запрещают шаблон. В блоке 4a пресет применяется к существующему проекту без `--template`. Почему: проект собирается вручную с зафиксированными мажорами (D-003). Проверить: токены в `tokens.css` совпадают с `docs/setup/inputs/shadcn-theme-tokens.css`.
- **A-002.** В облачной сессии git 2.43, а §0.4 требует ≥ 2.45. Принято как есть: среду обновить нельзя, возможности новее 2.43 проекту не нужны. Проверить: если команда git падает из-за версии — записать сюда.
- **A-003.** Push в `main` из сессии отклонён режимом разрешений (дважды, 2026-11-05). С согласия Кирилла коммит блока 0 запушен в `chore/setup`, а `main` создан из него через GitHub API (`create_branch`). Логика §0.5 не меняется: `main` начинается с коммита блока 0, блоки 1–7a идут в `chore/setup`, в 7a — PR в `main`. Проверить: `git log origin/main` начинается с `0e3fcfa`; основная ветка в настройках — `main`.
- **A-004.** `@vitejs/plugin-react` 6.x требует Vite 8, поэтому взят 5.2.0 — последняя версия с поддержкой Vite 7. Проверить: `npm view @vitejs/plugin-react@5.2.0 peerDependencies`.
- **A-005.** В `wrangler.jsonc` нет `account_id`: у `wrangler` в сессии нет токена, `wrangler whoami` недоступен. `wrangler deploy --dry-run` проходит и без него. Добавить `account_id` до первого деплоя в блоке 7a. Проверить: `pnpm exec wrangler whoami` после того, как Кирилл поставит токен.
- **A-006.** Опции генератора маршрутов вынесены в `tsr.config.json`: их читает и Vite-плагин, и `tsr generate` (`@tanstack/router-cli`), который запускается в `typecheck` перед `tsc`, чтобы `routeTree.gen.ts` был свежим без сборки. Context7 в сессии недоступен — имена опций сверены по коду установленного `@tanstack/router-generator`. Проверить: удалить `src/app/routeTree.gen.ts` и запустить `pnpm typecheck`.
- **A-007.** Иконки PWA — плейсхолдер (буква «T» на цвете `--primary` пресета), отрисованы из `public/icons/icon.svg` через Chromium; `Wordmark` появится в блоке 4a, полноценные иконки — v5.
- **A-008.** Снимок Drive (блок 1b) делали 7 субагентов, по 2–5 файлов на каждого, а не по одному на файл: так меньше накладных расходов, и проверка от этого не слабеет. Коннектор отдаёт содержимое в base64. Крупные ответы среда сохраняет в файл и раскодирует скриптом; мелкие субагент переписывает вручную. Поэтому кроме размера и UTF-8 каждый файл снимка сверен побайтно с исходным ответом коннектора из журнала сессии. Сверка нашла и исправила одну опечатку той же длины (`requirements-client.md`), которую проверка размера пропустила. Итог: 31 файл из 31 совпадает. Проверить: в блоке 8a `/sync-product-docs` должен сверять размер и содержимое, а не только размер.
- **A-009.** `docs/setup/master-prompt.md` — файл, который Кирилл передал в сессию (95 661 байт, v1.3). В Drive `05 Разработка/05-master-prompt.md` весит 95 287 байт и, видимо, отстаёт от переданного. Источником для работы считается переданный файл. Проверить: Кирилл подтверждает, какая версия актуальна, и при необходимости обновляет Drive.

# ADR-002 — Дизайн-система

**Статус:** принят (D-004, D-015, D-016, D-025, D-077) · **Дата:** 2026-11-04

**Контекст.** Бренда (палитры, логотипа) нет; есть требование двух письменностей, двух тем и запрета на «кредитную» агрессию; Figma-зеркала не будет.

**Решение.** shadcn/ui (Radix, RTL) как база, компоненты в `src/shared/ui`; токены — CSS-переменные oklch в `src/styles/tokens.css` с семантическими токенами статусов и прогресса лимита; две темы через `.dark`, по умолчанию системная (с 2026-11-11 — светлая, A-062), переключатель в настройках; шрифты: латинский — из пресета (по умолчанию Geist Variable), арабский — IBM Plex Sans Arabic через `:lang(ar)`, self-hosted; иконки lucide с явным списком зеркалируемых; Storybook — единственный источник документации компонентов (истории AR/EN × light/dark); основа темизации и токенов — пресет shadcn, который задаёт Кирилл в конструкторе тем shadcn (D-077); поверх него — семантические токены Tadum (статусы, прогресс лимита, движение), выведенные из палитры пресета; `shared/ui` и `tokens.css` защищены хуком, правки — через субагента `design-system-owner`.

**Последствия.** Дизайн задаётся Кириллом до разработки, агент не выбирает внешний вид; смена темы — новый пресет и правка одного файла; компоненты не содержат сырых значений (lint); цена — дисциплина токенов и отсутствие визуального редактора; при появлении бренда — обновление токенов и `Wordmark`, не компонентов.

# Tadum

B2B-портал для рынка KSA: кабинет клиента (заявка на торговый лимит, документы, статус, лимит) и кабинет поставщика (статус, реферальная ссылка и QR, приведённые клиенты, документы, условия) в одной оболочке. Фронтенд-прототип без бэкенда: все данные приходят из мок-адаптера, позже поверх портов подключится API.

Интерфейс по умолчанию на арабском (RTL), английский (LTR) равноправен; светлая и тёмная темы.

## Как запустить

Нужны Node 22 и pnpm 10 (версии в `.nvmrc` и `packageManager`).

```bash
pnpm install
```

```bash
pnpm dev
```

```bash
pnpm verify
```

Сборка под витрину — с базовым путём версии:

```bash
VITE_BASE_PATH=/p/tadum/v1/ pnpm build
```

Переменные окружения описаны в `.env.example`.

# Ревью текстов

1. Найди изменённые ключи: `git diff origin/main...HEAD -- src/shared/i18n/locales`.
2. `pnpm lint:i18n` — паритет и запрещённые слова.
3. Делегируй субагенту `ux-writer`: проверить каждый изменённый ключ по `.claude/rules/tov.md` и `tov-lexicon.json`, формы множественного числа арабского, формулу ошибок, длину строк на 360 px; поправить и записать в `docs/i18n/needs-review.md`.
4. Отчёт Кириллу: таблица ключ · было · стало · почему; вопросы владельцу текстов.

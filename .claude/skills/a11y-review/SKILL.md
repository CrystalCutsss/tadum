# Проверка доступности $ARGUMENTS

1. Определи маршруты и персоны (`README.md`); без аргумента — экраны, изменённые в ветке.
2. `pnpm test:a11y` — автоматический axe по экранам v1.
3. Делегируй субагенту `a11y-usability-reviewer`: клавиатура, фокус, подписи, читалка, цели касания, масштаб 200 %, обе темы и оба языка.
4. Отчёт Кириллу: блокеры, важное, мелочи — с критерием WCAG и предложением исправления.

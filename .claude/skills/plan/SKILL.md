1. Прочитай бриф (Drive `05 Разработка/Фичи`, файл `$ARGUMENTS-*.md`) и связанные сценарии. Нет брифа — предложи `/feature-brief`.
2. Изучи код вокруг: какие срезы `entities`/`features`/`widgets` уже есть, какие порты нужны (`src/shared/api/ports`), какие персоны и демо-действия мока покрывают сценарий.
3. Составь план:
   - изменения по слоям (`shared` → `entities` → `features` → `widgets` → `pages`), с путями файлов; соблюдай `docs/architecture/layers.md`;

   - что делегировать: `design-system-owner` (новые компоненты, токены), `ux-writer` (тексты);
   - риски и открытые вопросы.
4. Покажи план Кириллу; после согласия — запиши в раздел 13 брифа (новая версия файла в Drive) и предложи ветку `feat/$ARGUMENTS-<коротко>` (или worktree, `CONTRIBUTING.md`).

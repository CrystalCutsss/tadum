# ADR: $ARGUMENTS

1. Номер — следующий после последнего `docs/decisions/ADR-*.md`; slug — английский, через дефис.
2. Структура как у ADR-001…003 (русский): заголовок `# ADR-NNN — <название>`, строка «Статус · Дата», разделы **Контекст**, **Рассмотрено** (варианты), **Решение**, **Последствия** (плюсы, минусы, когда пересмотреть). Ссылки на D-### из `docs/product/00-decision-log.md`, если есть.
3. Решение, которого нет в журнале решений, — статус «предложено»; принимает Кирилл.
4. Добавь строку в таблицу `docs/README.md`; `pnpm check:docs`.
5. Копия — Drive `05 Разработка/ADR` (`1V4wbfmUgvKfdf9K4gDU1Bbk8BFeYX-Yw`), размер сверить.

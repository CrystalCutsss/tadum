# Дизайн-ревью

1. Определи изменённые экраны и компоненты: `git diff --name-only origin/main...HEAD`.
2. Статика: `pnpm lint` (токены, сырые значения), `pnpm check:contrast`, поиск в дифе прямых импортов Radix/иконок мимо `shared/ui`.
3. Скриншоты: `pnpm screenshots`; для компонентов — `pnpm storybook:build` и истории в матрице.
4. Проверь по `docs/design/02-design-system.md` и ADR-002: только компоненты `shared/ui`, иерархия и отступы на токенах, состояния (skeleton, пусто, ошибка, офлайн), светлая и тёмная темы, 360/768/1280, длинные арабские строки.
5. Нужны новые компоненты или токены — не правь сам, оформи задачу субагенту `design-system-owner`.
6. Отчёт (русский): экран · что не так (путь к скриншоту) · правило · предложение; отдельно — задачи для `design-system-owner`.

# Снимок продуктовых документов

- `docs/product/**` — дословная копия Google Drive (шапка `<!-- source: Drive … -->`). Руками не править никогда.
- Обновление — только скилл `/sync-product-docs` (Кирилл запускает его в сессии `TADUM_DOCS_SYNC=1 claude`), отдельный PR `docs: sync product docs YYYY-MM-DD`.
- Нашли ошибку или противоречие — предложить правку текстом Кириллу (что, где, почему); после правки в Drive — синхронизация.
- Код при расхождении с документом не «чинит» документ: решение фиксируется в Drive, допущение до решения — в `docs/decisions/assumptions.md`.
